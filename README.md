# Snack Shop Management

Website quản lý cửa hàng bánh kẹo / đồ ăn vặt (dự án cá nhân).

## Cấu trúc

```
.
├── frontend/        # giao diện người dùng (chưa khởi tạo)
├── backend/         # API + xử lý nghiệp vụ (chưa khởi tạo)
├── docs/            # harness — tài liệu giúp AI/dev bám tiến độ
├── AGENTS.md        # luật làm việc cho AI (đọc đầu tiên)
└── README.md
```

## Làm việc với AI

1. Mở AI agent tại thư mục gốc của repo.
2. Prompt khởi động:
   > Đọc AGENTS.md và docs/STATUS.md, cho tôi biết dự án đang ở đâu và 3 việc tiếp theo cần làm.
3. Khi kết thúc phiên, yêu cầu AI cập nhật `STATUS.md`, `TASKS.md`, `LOG.md` để phiên sau không bị mất ngữ cảnh.

## Trạng thái hiện tại

Xem [`docs/STATUS.md`](docs/STATUS.md).

- Phase 0 — khởi tạo repo & harness.
- Chưa chốt tech stack và phạm vi MVP.

## Chạy dự án

Chưa có — `frontend/` và `backend/` đang trống. Hướng dẫn sẽ được thêm vào `docs/SETUP.md` sau khi chốt stack.
